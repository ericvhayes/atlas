## Retrieval Process

1. **Tier 0**: Check `.ai/memory/MEMORY.md` and today's daily log — already in context
2. **Tier 1**: Read recent daily logs from `.ai/memory/daily/` (past few days)
3. **Tier 2**: If memsearch is available, run `memsearch search "query" --top-k 5`
4. **Tier 3**: If memsearch is available, run `memsearch expand <chunk_hash>`
5. **Fallback**: "I don't have a record of that."
